::Transitional Node::

  -> ResolveEnvBinding: A not yet resolved binding reference. Eventually resolves into EnvBinding, RemoteEnvBinding,
     GlobalBinding, ScriptBinding.

  -> JSImplicitBindingDeclaration: A declaration for context specific bindings such as `arguments`, `this`...etc
     Resolves into an LWrite statement with the INIT flag set.

  -> TDZRead: Before any write statement such as `a = b = c`, TDZ checks must be inserted in the L to R order
     (opposite of the effect order). In order to accomplish this, this node was introduced. It adds explicit read
     operations before the statements to mimmic TDZ checks (L-R ordering).
     Under certain circumstances, this is incorrect hence the transitional nature. More specifically in case of
     sloppy-mode---script-level code, writes to GlobalBinding (i.e. bindings not declared anywhere in the script
     a.k.a. ScriptBinding) must write directly to the global environment.

  -> JSExplicitBindingDeclaration: Declares the binding in scope, sets TDZ zone at the relavant scope start and
     sets up default TDZ exit init. If not initial value is provided, it defaults to undefined.

  -> JSExplicitBindingDeclarationN: Declares the binding in scope, no TDZ zone is set and initialization is generally
     known to be safe (temporaries introduced during codegen). If not initial value is provided, it becomes a NOP inst.

  -> JSExplicitBindingDeclarationX: Same as JSExplicitBindingDeclarationN, but additionally marks the declared binding
     as ArgX. This basically guarantees that any subsequent write to this binding will be safe, but reading it before
     it is written to atleast once will result in a TDZ read error. This was needed to implement the default argument
     initialization functionality.

  -> UnresolvedReturn: Turns out it is not correct to replace `return` with `return undefined`. In case of derived class
     constructors, we must always return the `this` object if nothing is specified.

  -> JSFuncDecl: Hoisting rules for function declarations is complex and heavily context dependent, this means we cannot
     trivially lower these nodes into the form `a = function a() {}` always. This provides a placeholder intermediate.

  -> EnvWrite: Until LVAL targets are resolved, this acts as a placeholder generic write. Once resolved, it transitions to
     a more specialized LWrite, GWrite, RWrite.

  -> SiblingSpecialWrite: This is the same as EnvWrite with the exception that the LVAL is resolved in a specific (possibly
     sibling) scope. This was needed to model the semantics default argument initializations.

  ->

::Primitives::

  -> String

  -> JSNUBD: A special binding that stands for No-Use Before Def semantics. All EnvReads that reference this value will fail.
     All EnvWrites which have an LVAL having this value will fail (unless marked as INIT or SAFE).

  -> JSClass

STMT := JSExplicitBindingDeclarationN     {Transitional}
      | JSExplicitBindingDeclaration      {Transitional}
      | JSFuncDeclSEXP                    {Transitional}
      | SiblingSpecialWrite               {Transitional}
      | ResolveContinueTarget             {Transitional}
      | ResolveBreakTarget                {Transitional}
      | JSImplicitBindingDeclaration      {Transitional}

      <-- Env OPs -->
      | LWrite
        - XWrite  - Non Aliased binding local stack binding
        - LWrite  - Aliased local stack binding
      | RWrite
        - XRWrite - Exclusive ownership over remote binding
        - RWrite  - Non exclusive owenership over remote binding
      | FieldWrite
        - LFWrite
        - RFWrite
        - JSGFWrite
      | GWrite
        - JSGWrite
      | JSSloppyFuncDecl + JSSloppyDecl
        - JSGDecl
      | JSSuperFieldWrite
        - JSSFWrite
      | JSComputedFieldWrite
        - JSCFWrite
      | JSPrivateFieldWrite
        - JSPFWrite

      <-- CFlow -->
      | ReturnAsync
      | Return
      | IfJump                            {Only-Execution-Target}
      | IfElseJump
      | Goto

      <-- Async CFlow -->
      | JSInitialYield
      | Yield

      <-- Err Handling -->
      | PushCatchContext
      | Throw
      | PopCatchContext
      | InvokeFinalizer
      | Ret
      | PopFinalizerReturnTarget

      <-- Stack OPs -->
      | StackReject
      | StackRetain

      <-- Loop Related -->
      | LoopInitPreludeEnd

      <-- Garbage -->
      | NOP
